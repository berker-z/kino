# ditherPass and scripts/dither.py

One dither tool in two halves that share their settings. `ditherPass` dithers anything a composition paints: a canvas source, or a photo with a camera move. `scripts/dither.py` dithers files: a photo, or real footage, in and out. Footage goes through the script and then into a composition as an ordinary `<video>`. Drawing a playing `<video>` into a canvas during a HyperFrames render isn't frame-reliable, and the script can do things a seek-anywhere render can't.

The research behind every default is in `research/dither/` (`index.html` for round one, the Doré recipe; `tool.html` for round two, this tool).

```js
Kino.ditherPass(stage, tl, {
  width: 2560, height: 1440, scale: 2, duration, fps: 30,
  method: "bayer-8", palette: "sepia-3", prep: "punch",
  paint: (ctx, t) => { /* grayscale, full size, white = light */ },
});
```

```
python3 scripts/dither.py clip.mp4 -o out.mp4 --size 2560x1440
python3 scripts/dither.py clip.mp4 -o out.mp4 --method floyd-steinberg --hyst 0.35
python3 scripts/dither.py photo.jpg -o out.png --palette "#101010,#6b5a44,#e8dcc6"
```

## Three stages

**Prep** is what decides whether a photo reads. Round one fed photos in raw and they dithered into mud. `punch` stretches levels (1st and 99th percentile), adds local contrast (a wide unsharp mask, radius 24 dither px, amount 0.6), applies an S-curve (0.35) and sharpens a little (radius 1, amount 0.7). Levels are measured once, never per frame: per-frame levels make the exposure pump. The pass measures the frame at `levelsAt` (default 0) at setup; the script measures every 15th frame of the clip.

**Method** turns tone into pattern against a fixed threshold map:

- `bayer-8`, the default and Berker's pick: the regular cross-hatch of old computers and games.
- `blue-noise`, the second choice: a fixed grain with no visible pattern. A 64×64 void-and-cluster tile (Ulichney), generated by `scripts/dither_engine.py` and embedded in `src/passes/blue-noise.ts`, so both halves make the same grain.
- `bayer-4`, coarser; `halftone`, round dots on a 45° screen.

The maps are fixed to the screen, so a pixel only changes where the picture does. Measured on four clips, the boil (pixels flipping where the source didn't change) was 0.2 to 0.7% for all of them.

**Palette**: 2 to 4 colours, dark to light. N colours = N tones. Three is the sweet spot: two dark colours close together (the sepia pair) look moody but dither into a grey smear; a third, light tone gives highlights somewhere to go. Presets in `ditherPalettes` (and in the script): `sepia-2/3/4`, `ice-2/3`, `prussian-3`, `oxblood-3`, `phosphor-3`, `bone-2`, `paper-3`.

**Amount** is how much it dithers, 0 to 1. At 1 the picture is dithered to exactly the palette. Lower adds evenly spaced in-between tones along the palette's ramp (the step shrinks linearly from 1/(N-1) towards 1/255), so the pattern's steps get smaller and softer; at 0 it's a smooth gradient map with no pattern. A painter can return `{amount}` per frame to dissolve a shot into dither and back. The script takes `--amount`.

**Scale** is screen px per dither px. 2 at 1080p; 2 or 3 at 1440p. 1 is finer than reads as dither; 4 is pixel art.

## The playground

`npm run playground` builds and serves the repo, then open http://127.0.0.1:8077/tools/dither/. Sliders for amount, pixel size, pattern, palette (with colour pickers) and every prep setting, on sample photos, the research footage, or anything you drop in, video included. It shows the matching `ditherPass` options and `scripts/dither.py` command to copy. It uses `Kino.ditherer`, the same per-frame code the pass runs. (It needs the server: a page opened from disk can't read pixels from local images.)

## Error diffusion lives in the script only

Floyd-Steinberg and Atkinson make the best stills, and they boil in motion: every small change upstream moves every pixel after it. Plain Floyd-Steinberg flipped 13 to 22% of pixels per frame where nothing had changed. The fix is hysteresis (`--hyst 0.3` to `0.4`): a pixel keeps last frame's tone unless its value clearly moves past the threshold. That cut the boil to 0.5 to 3%. It needs the previous frame, which a HyperFrames render doesn't have (it can seek to any frame in any order), so the pass doesn't offer error diffusion at all.

## Gotchas

- Paint grayscale, full size. The pass shrinks to dither resolution itself (`width / scale`, rounded up; the upscale is cropped back to exact size).
- `paint` can return `{bias}` per frame (-1 to 1): a fade that happens after prep, so auto levels and local contrast don't fight it.
- The ImageMagick recipe from the Doré post (`-dither FloydSteinberg -monochrome`) doesn't dither: IM7's `-monochrome` ignores `-dither` and thresholds at 50%. Use `-remap` or `-colors 2`, or this tool.

## Regenerating the blue-noise tile

```
python3 -c "import sys; sys.path.insert(0, 'scripts'); import dither_engine as E; print(E.blue_noise().shape)"
```

The TS module was written from that tile (ranks as uint16, base64). If you change `blue_noise()`'s parameters, rewrite `src/passes/blue-noise.ts` the same way so the two halves stay identical.
